## תצורת הגשה

החבילה מורכבת מתיקיית Markdown ודף QA מקושר ב־Notion. מסמכי Markdown ואינדקס הראיות נכללים בגבול הדחיפה המאושר; לא נוצר release artifact או Docker image להפצה. קישורי temp שלהלן נשארים מקומיים גם לאחר פרסום המסמכים ב־Git.

1. **מסמכים:** ששת קובצי ה־Markdown בתיקייה זו ואינדקס הראיות.
2. **ראיות מקור:** E01–E06 לפי ה־manifest. הן נשארות בתיקיית `temp/rc0-20260827-01`, ללא שינוי. E07–E10 הם קוד עזר לביקורת מקומית, לא הוראות הפעלה מוכנות.
3. **רישום סקירה:** הסוקר ממלא שם, תאריך, גרסת מסמך, הערות והחלטת `ACCEPT_DOCUMENTATION` או `RETURN_FOR_CORRECTION`. שדה אישור שחרור נשאר נפרד; אין חתימה אוטומטית בשם Idan.

לתיקייה `temp/` יש החרגה קיימת מ־Git. קישור מקומי לראיות אינו נגיש אוטומטית לסוקר GitHub/Notion. לפני הגשה מרוחקת יש לקבוע נמען וערוץ מורשים, לבדוק redaction ונגישות, ולהעביר **רק** allowlist מפורש. לא בוצע upload של קובצי הראיות או פרסום PR בסבב זה.

אין לצרף repo מלא, `.env*`, credentials, נתוני runtime/permissions/audit אמיתיים, `node_modules`, volumes, או image. ה־image הנגזר של ההרצה הכיל שכבות בסיס שלא נוקו, היה מוסתר בזמן הריצה בלבד, וכבר הוסר. `snapshot/` הוא ניסיון staging לא שלם; המקור התקין הוא `snapshot-02/source` בלבד.

SHA-256 מאמת זהות בתים מול האינדקס; אינו חתימה, redaction אוטומטי או הוכחת היעדר סודות. עריכה/השחרה לצורך מסירה מחייבת עותק חדש, תיאור שינוי ו־hash חדש, תוך שימור המקור.
