# אבטחת שרת רישיונות SafeSoundArena

מסמך זה מתאר את אמצעי האבטחה המיושמים בשרת הרישיונות של SafeSoundArena ואת הנהלים המומלצים לשמירה על אבטחת המערכת.

## אמצעי אבטחה מיושמים

### אימות והרשאות

- **JWT לאימות מנהלים**: כל פעולות הניהול דורשות JWT תקף עם הרשאות מנהל.
- **פקיעת טוקנים**: כל טוקן JWT פג תוקף לאחר שעה אחת.
- **חתימות HMAC**: אימות מידע המערכת באמצעות חתימות HMAC.

### הגנה מפני התקפות

- **הגבלת קצב בקשות**: מניעת התקפות brute-force באמצעות הגבלת מספר הבקשות לכל IP.
- **Helmet**: הגנות HTTP בסיסיות, כולל הגדרת כותרות אבטחה.
- **CORS**: הגבלת גישה למקורות מורשים בלבד.
- **סניטציה של קלט**: ניקוי וולידציה של כל קלט משתמש.
- **הגנה מפני SQL Injection**: שימוש בפרמטרים מחייבים ולא בשרשור מחרוזות.
- **הגנה מפני XSS**: סניטציה של פלט וכותרות אבטחה מתאימות.

### הצפנה ואבטחת מידע

- **הצפנת סיסמאות**: סיסמאות מנהל מאוחסנות בצורה מוצפנת.
- **מפתחות הצפנה**: שימוש במפתחות הצפנה ייחודיים לכל התקנה.
- **אחסון מאובטח**: מידע רגיש מאוחסן בצורה מאובטחת.

### תיעוד ובקרה

- **לוגים מפורטים**: רישום של כל פעולות האימות והניהול.
- **מזהה בקשה ייחודי**: כל בקשה מקבלת מזהה ייחודי לצורכי מעקב.
- **תיעוד אירועי אבטחה**: רישום מפורט של אירועי אבטחה חריגים.

## נהלי אבטחה מומלצים

### התקנה ותצורה

1. **שינוי סיסמאות ברירת מחדל**: שנה את כל סיסמאות ברירת המחדל מיד לאחר ההתקנה.
2. **הגדרת משתני סביבה**: הגדר את כל משתני הסביבה הנדרשים בקובץ `.env` מאובטח.
3. **הרשאות קבצים**: הגדר הרשאות קבצים מינימליות הנדרשות לפעולה תקינה.
4. **HTTPS**: הפעל את השרת תמיד עם HTTPS בסביבת הייצור.
5. **הגבלת גישה**: הגבל את הגישה לשרת הרישיונות לרשתות מורשות בלבד.

### ניהול מפתחות וסודות

1. **רוטציית מפתחות**: החלף מפתחות הצפנה וחתימה באופן תקופתי.
2. **אחסון מאובטח**: אחסן מפתחות וסודות במערכת ניהול סודות מאובטחת.
3. **הפרדת סביבות**: השתמש במפתחות שונים לסביבות פיתוח, בדיקות וייצור.

### ניטור ותגובה לאירועים

1. **ניטור שוטף**: בצע ניטור שוטף של לוגים ואירועי אבטחה.
2. **התראות**: הגדר התראות לאירועי אבטחה חריגים.
3. **תכנית תגובה**: פתח תכנית תגובה לאירועי אבטחה.
4. **גיבויים**: בצע גיבויים תקופתיים של נתוני הרישיונות.

## עדכון ותחזוקה

1. **עדכוני אבטחה**: התקן עדכוני אבטחה באופן שוטף.
2. **בדיקות אבטחה**: בצע בדיקות אבטחה תקופתיות.
3. **סקירת קוד**: בצע סקירות קוד לזיהוי בעיות אבטחה.

## דיווח על פגיעויות

אם גילית פגיעות אבטחה בשרת הרישיונות, אנא דווח עליה באופן אחראי באמצעות:

1. שליחת דוא"ל מוצפן לכתובת security@safesoundarena.com
2. תיאור מפורט של הפגיעות והשלבים לשחזורה
3. אי פרסום הפגיעות לפני שניתנה לנו הזדמנות סבירה לטפל בה
