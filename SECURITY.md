# מדיניות אבטחה - SafeSoundArena

## גרסאות נתמכות

הגרסאות הבאות של הפרויקט נתמכות כרגע עם עדכוני אבטחה:

| גרסה  | נתמכת              |
| ----- | ------------------ |
| 1.0.x | :white_check_mark: |
| < 1.0 | :x:                |

## דיווח על פרצות אבטחה

אנו מעריכים את עזרת הקהילה בזיהוי בעיות אבטחה פוטנציאליות בפרויקט שלנו. אם גילית פרצת אבטחה, אנא דווח עליה באמצעות:

1. פתיחת דיווח פרטי בכתובת security@safesoundarena.com
2. כלול תיאור מפורט של הבעיה, כולל צעדים לשחזור
3. אם אפשרי, הצע פתרון או דרך למזער את הסיכון

אנו מתחייבים להגיב לדיווחי אבטחה תוך 48 שעות ולעבוד על תיקון בהקדם האפשרי.

## מדיניות הגנה על קניין רוחני

פרויקט SafeSoundArena מוגן תחת רישיון כפול (MIT + PiOS) ומכיל מנגנוני הגנה מפני שכפול והעתקה לא מורשים:

1. **סימני מים דיגיטליים** - כל המסמכים והקבצים הגרפיים מכילים סימני מים דיגיטליים נסתרים
2. **מפתחות רישיון** - הפעלת גרסאות ייצור דורשת מפתח רישיון תקף
3. **בדיקות אותנטיות** - המערכת מבצעת בדיקות תקופתיות לוודא שהקוד לא שונה בצורה לא מורשית
4. **הגנת קוד** - חלקים קריטיים של הקוד מוצפנים ומוגנים מפני הנדסה לאחור

## שימוש בפרויקט

כל שימוש בפרויקט חייב לעמוד בתנאי הרישיון ובמדיניות האבטחה. שימוש לא מורשה או הפרת תנאי הרישיון עלולים להוביל לפעולות משפטיות.

## מדיניות עדכונים

אנו מפרסמים עדכוני אבטחה באופן שוטף. מומלץ לעקוב אחר הערוץ הרשמי שלנו לקבלת התראות על עדכונים חשובים.

# Security Policy - SafeSoundArena

## Supported Versions

The following versions of the project are currently supported with security updates:

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability

We value the community's help in identifying potential security issues in our project. If you discover a security vulnerability, please report it by:

1. Opening a private report at security@safesoundarena.com
2. Including a detailed description of the issue, including steps to reproduce
3. If possible, suggesting a solution or mitigation

We commit to responding to security reports within 48 hours and working on a fix as soon as possible.

## Intellectual Property Protection Policy

The SafeSoundArena project is protected under a dual license (MIT + PiOS) and contains mechanisms to prevent unauthorized duplication and copying:

1. **Digital Watermarks** - All documents and graphic files contain hidden digital watermarks
2. **License Keys** - Running production versions requires a valid license key
3. **Authenticity Checks** - The system performs periodic checks to verify that the code has not been modified in an unauthorized manner
4. **Code Protection** - Critical parts of the code are encrypted and protected against reverse engineering

## Project Usage

All use of the project must comply with the license terms and security policy. Unauthorized use or violation of license terms may lead to legal action.

## Update Policy

We publish security updates on an ongoing basis. It is recommended to follow our official channel for alerts about important updates.
